## [1.0.0] — 2025-11-07

### Added
- Базовый функционал бронирования охотничьих туров
- API:
  - `GET /api/v1/guides` — список активных гидов с фильтрацией по опыту  
  - `POST /api/v1/bookings` — создание нового бронирования
- Проверки бизнес-логики:
  - гид должен быть активным  
  - уникальность даты (гид не может быть занят дважды)  
  - количество участников ≤ 10  
  - дата не может быть в прошлом
- Глобальный обработчик ошибок (единый JSON-формат)
- DTO, FormRequest, Resource — чистая структура в стиле Laravel 11
- Unit и Feature тесты (15+ успешных проверок)
- Сидеры и фабрики для генерации тестовых данных
- Поддержка запуска через Laravel Sail (Docker-ready)

### Architecture
- Отдельные слои: DTO → Service → Resource  
- Контракты для доменных ошибок (`BookingException`)
- Чёткая изоляция бизнес-логики в сервисах
- Единообразный формат ошибок через глобальный рендер

### QA
- 100% успешное прохождение тестов
- Валидационные сообщения адаптированы под русский язык
- Тесты Feature и Unit разделены по зонам ответственности
